## 🚀 Featured Projects

### 🩺 [Breast Cancer Diagnosis — End-to-End ML Pipeline](https://github.com/okfaygo/breast-cancer-diagnosis)
A full ML lifecycle project: EDA → preprocessing → neural net → error analysis → ensembling → deployed web app.

- Trained a TensorFlow/Keras classifier on the WDBC dataset; a soft-voting ensemble with tuned thresholds reached **1.000 recall / 1.000 precision** on the test split
- Diagnosed *why* a "100% accuracy" dataset was misleading and switched to one with real, studyable errors — the kind of judgment call that matters more than the metric
- Re-implemented the neural net **and** the tree models in pure NumPy so the deployed Streamlit app cold-starts in under a second with no TensorFlow dependency (~20 KB model bundle)
- Exporters verify NumPy parity against the original libraries across all 569 samples and refuse to write a mismatched bundle

`TensorFlow` `scikit-learn` `NumPy` `Streamlit` `Hugging Face Spaces`

### ⚙️ [CI/CD for ML](https://github.com/okfaygo/cicd-for-ml)
An MLOps pipeline that automates model training, evaluation, and reporting through GitHub Actions.

- Makefile-driven workflow: train, evaluate, and publish metrics on every push
- Versioned model and results artifacts so experiments stay reproducible

`GitHub Actions` `Python` `Makefile` `scikit-learn`

### 🈳 [Dokkan Translation](https://github.com/okfaygo/dokkan-translation)
An Android app that translates in-game card details for Dokkan Battle in real time.
